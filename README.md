

# Проект - Vanessa_QA_UT_BLR

# Описание
 Проект для автоматизации тестирования (QA) конфигурации «1С:Управление торговлей для Беларуси, редакция 3.5».
 
 Его основное назначение — создание сценарных тестов для конфигурации «1С:Управление торговлей для Беларуси, редакция 3.5»,
 (с использованием Gherkin и vanessa-automation) для конкретной конфигурации 1С.
 
 Проект структурирован и периодически обновляется.

## Для написания сценарных тестов использовался инструмент:
  [vanessa-automation](https://github.com/Pr-Mex/vanessa-automation)
