 
 # Описание файла настроек подключения - ctt_by
	 connection_setup_ctt_by.json
 Расширение файла - .json
 Имя файла - connection_setup_ctt_by
 
Файл с настройками должен распологать в папке - setting, которая должна находиться в директории проекта указаной в настройках - vanessa-automation.

      {
    	  "login": "my_login",
    	  "parol": "my_parol"
     }
     
В значении login, указываем логин подключения.
В значении parol, указываем пароль подключения.
#### Пример:
      {
    	  "login": "admin_test",
    	  "parol": "1234sdsd5678ww09888"
     }
